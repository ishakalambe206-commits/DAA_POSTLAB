07 THEORY QUICK GUIDE

What is TSP?

Given a set of cities and travel costs between them, find a minimum-cost tour that visits every city exactly once and returns to the starting city.

DP State

dp[mask][i] represents the minimum cost to start at A, visit exactly the cities represented by mask, and finish at city i.

Transition

To reach i, try every previously visited city j and use dp[mask without i][j] + distance[j][i]. Store the smallest value.

08 ALGORITHM

Held–Karp Dynamic Programming Algorithm

  1. Fix City A as the starting city.
  2. Represent each visited-city set with a bitmask.
  3. Initialize dp[{A}][A] = 0 and all other starting states as infinity.
  4. For each subset, compute the cheapest way to reach every possible ending city.
  5. Use the transition: dp[S][i] = min(dp[S−{i}][j] + d[j][i]).
  6. After all cities are visited, add the cost of returning from the final city to A.
  7. Backtrack through the parent table to reconstruct the optimal tour.
for each subset S containing A
  for each ending city i in S, i ≠ A
    dp[S][i] = min over j in S−{i} of (dp[S−{i}][j] + d[j][i])
answer = min_i (dp[ALL][i] + d[i][A])
